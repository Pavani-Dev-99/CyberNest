UI/UX Task – Cybersecurity Learning & CTF Platform

We are building a cybersecurity education + hands-on practice platform, similar in concept to TryHackMe, Hack The Box and LeetCode.

The purpose is to let users:

Learn cybersecurity concepts
Practice through real-world labs
Solve CTF/challenges
Follow learning paths
Track progress, XP and achievements
Compete through leaderboards
Read/write technical writeups

Important: This is not a cybersecurity services/company website. Don't design it like a corporate VAPT/security-services website.

UI direction

Keep the design:

Simple and minimal
Clean and professional
Easy to read for long sessions
Consistent across all pages
Minimal colors, preferably a neutral base with one primary brand color
Good typography, spacing and visual hierarchy
Clear cards and sections
Minimal animations, gradients, glow and unnecessary effects

You can use TryHackMe, Hack The Box, LeetCode and other modern learning platforms as UX references, but do not copy their UI, branding, logo or visual identity.

First focus on creating a common design system: colors, fonts, spacing, buttons, cards, inputs, badges, navigation, tables, etc. Then use that system consistently for the dashboard, labs, lab details, challenge workspace, learning paths, leaderboard, profile, etc.

Goal: The platform should feel like a place where a cybersecurity learner can comfortably spend hours learning → practicing → solving → progressin
